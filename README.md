# CodeWithAzam — Python & AI for Senior Engineers

Side-by-side Java and Python code examples from the **CodeWithAzam** YouTube channel.
Every concept is shown in Java first (what you know) then Python (what you're learning).

## How to Use This Repo

```bash
# Clone
git clone https://github.com/AzamMehr/code-with-azam.git
cd code-with-azam

# New to Python? Start here — install uv, Python, and Jupyter
cd video-00-setup
# Follow README.md, then run:
python verify_setup.py

# Run a Java example (Video 01+)
cd video-01-syntax-basics/segment-01-first-impressions
javac HelloWorld.java && java HelloWorld

# Run a Python example
cd video-01-syntax-basics/segment-01-first-impressions
python hello_world.py

# Run all Python segments for a video
cd video-01-syntax-basics
python run_all.py

# Practice (Videos 00-06 include Jupyter notebooks)
cd video-01-syntax-basics
jupyter notebook practice.ipynb
```

## Prerequisites

- **Java**: JDK 17+ (examples tested on Java 21)
- **Python**: 3.10+ (examples use `match/case` and walrus `:=`)
- **Recommended**: Install [uv](https://docs.astral.sh/uv/) for Python project management (covered in Video 00)
